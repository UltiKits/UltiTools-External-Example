# UltiTools External Plugin Example — UAT Checklist

Run against a disposable Paper 26.3 server with UltiTools-API 7.0 and the sample JAR both in `plugins/`. Before starting, match the installed sample's SHA-256 to the build hand-off. Keep the server's data and configuration directories intact across the restart row. A wrong build or unavailable client is a setup blocker, not a product failure.

## Conventions

- IDs match `FEATURES.md`; `.neg-*` and `.alt-*` rows cover additional cases of the same feature. Any row referenced as a precondition must precede the reference. No GUI-exclusion class applies (`Covers` is blank).
- Console commands below have no leading `/`. Client commands include it. Use an isolated server with no competing `ultiext` or `uext` command, no permission overrides unless specified, and no unrelated joins during storage checks.
- Use a fresh observation window for each command or join. Compare message text without the console's timestamp/logger prefix; preserve spacing inside the message. Sample replies are in English. For the one framework usage reply below, start with `language: en` and `fallback-language: en` in the framework config.
- A join automatically records the joining player's name. Where a row needs a specific record state, verify it with console `ultiext visitors`; use `ultiext delvisitor <name>` to reset that name. Never delete records on a shared server.
